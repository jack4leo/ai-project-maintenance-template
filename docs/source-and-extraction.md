## General Mechanism Abstracted

`AGENTS.md` is task routing rather than a second copy of the rules; the responsibility list directs the agent to read the relevant reference for each task. Subsystem pages center on responsibility boundaries, authoritative sources, runtime paths, status/constraints, failure and compatibility, and verification evidence, and are updated together when the described behavior changes. Code standards cover implementation quality, failure handling, test isolation, and honest reporting; community contribution review separately handles untrusted code, permissions, and maintainer decisions; Lessons preserve each project's own rework and verification lessons, retaining dates and evidence and promoting them to stable standards only after repeated verification.

Magpie's documentation is extremely detailed and strongly dependent on that product. Abstracting each rule into a hard rule for every project would cause errors. Therefore, this repository treats only the maintenance protocol as a baseline; the project's commands, subsystem boundaries, risk model, compatibility requirements, and lessons must be discovered from the target repository through [`prompts/bootstrap-project.md`](../prompts/bootstrap-project.md) and continuously maintained by subsequent agents.
